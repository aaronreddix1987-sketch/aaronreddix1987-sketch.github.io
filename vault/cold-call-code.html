The Cold Call Code

AI Phone Agent & Trust-Building Playbook

1. Script Is a Skeleton

Know the one outcome of the call. Adapt to what they actually say.

2. Seven Seconds to Earn Trust

First words prove you are not a threat and not a waste of time.

3. Qualify Before You Pitch

Ask a real question first. Only pitch if they have the problem you solve.

4. Never Argue With a No

One respectful follow-up. Then let go gracefully.

5. End With One Clear Ask

Callback, email, or permission to send info — always one specific next step.
